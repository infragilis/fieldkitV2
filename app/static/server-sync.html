Server Sync

Download content from the Fieldkit server into the local data and personal libraries.

Automatic checks run 10 minutes after the kit boots, then every hour. The page does not need to stay open.

Data folders: ontap · bes · cisco · nvidia · fos. Server file paths determine which folder receives each download.
